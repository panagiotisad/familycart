# FamilyCart – Shared Grocery List & offers finder

A Progressive Web App (PWA) that allows families and groups to share a grocery list and discover available offers on listed products.

### Features

- Shared grocery lists 
- Real-time list updates between users
- Supermarket offers scraper for collecting available deals
- Automatic product matching between grocery list items and supermarket offers
- Direct links to products with available offers

### Technologies

Python · Flet 

### Deployment

Hosted on Oracle Cloud.

**Live Demo:** [https://familycart.duckdns.org](https://familycart.duckdns.org)

### Installation for mobile devices

FamilyCart is a Progressive Web App, meaning you can install it directly from your browser without downloading it from an app store.

**Android**
1. Open [FamilyCart](https://familycart.duckdns.org) using Google Chrome.
2. Tap the three-dot menu in the top-right corner.
3. Select **Install app**.
4. FamilyCart will appear on your home screen like a regular app.

**iPhone**
1. Open [FamilyCart](https://familycart.duckdns.org) using Safari.
2. Tap the **Share** button.
3. Scroll down and select **Add to Home Screen**.
4. Tap **Add** in the top-right corner.
5. FamilyCart will appear on your home screen like a regular app.
